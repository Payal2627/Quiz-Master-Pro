# Quiz Master Pro

Quiz Master Pro is an advanced terminal-based Quiz Management System built entirely using Core Python. The project follows Object-Oriented Programming principles and provides separate functionalities for Admin and User roles.

## Features

### User Module

* User Registration
* User Login Authentication
* Category-Based Quiz Selection
* Difficulty-Based Quiz Selection
* Random Question Generation
* Score Calculation
* Percentage Calculation
* Grade Generation
* Wrong Answer Review
* Quiz History Tracking
* Performance Analysis
* Leaderboard Access
* Statistics Dashboard
* Secure Logout

### Admin Module

* Admin Login
* Add Questions
* View Questions
* Search Questions
* Edit Questions
* Delete Questions
* Manage Quiz Database

### Data Storage

The application stores users, questions, and quiz results permanently using Pickle files, allowing data to persist even after the program is closed.
